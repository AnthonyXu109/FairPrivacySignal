# Non-Confidentiality Statement

FairPrivacySignal is a public, non-confidential project.

This repository does not use, disclose, depend on, or derive from:

- Meta confidential information
- Meta internal datasets
- Meta internal architecture
- Meta internal project names
- Meta internal metrics
- Meta product-specific implementation details
- Meta proprietary code
- Any real user-level personal data

All event-level data used in this project is synthetic. Public datasets, if referenced, are used only as aggregate background or calibration sources and are not used to identify individuals.

The project is designed to demonstrate general, non-confidential engineering patterns for privacy-preserving and fairness-aware AI ranking and matching under signal loss.
